# 水木社区“添加版面收藏”模式 API 文档

## 1. 接口概述

该接口用于将指定版面添加到用户的收藏夹中。
当前 App 实现采用“发送即遗忘”模式，发送请求后假设成功，并不解析服务端返回的响应。

- **URL**: `https://www.newsmth.net/bbsfav.php`
- **HTTP 方法**: `GET`
- **编码**: GBK (URL 参数需编码)

## 2. 请求参数

| 参数名 | 必填 | 示例值 | 描述 |
| :--- | :--- | :--- | :--- |
| `bname` | 是 | `Apple` | 版面英文名称 |
| `select` | 是 | `0` | 操作类型标记。`0` 通常代表添加操作。 |

**请求 URL 示例**:
`https://www.newsmth.net/bbsfav.php?bname=Apple&select=0`

## 3. 响应解析

### 3.1 当前 App 行为
App 发起请求时未指定解析器 (`parser: nil`)，也未监听回调。
因此，App **完全忽略**服务端返回的任何内容（HTML 或 JSON），仅在 UI 层提示用户“已添加至离线版面列表”（实际上也尝试了添加到线上收藏夹）。

### 3.2 建议的改进
重构时，建议检查 HTTP 响应状态码（200 OK）以及响应内容，以确认操作是否真正成功。
通常如果操作成功，服务端可能会返回一个包含成功提示的 HTML 页面或重定向。如果未登录或参数错误，可能会返回错误提示。

## 4. 离线收藏
除了调用上述 API 添加到云端收藏夹外，App 还会调用本地方法将版面添加到本地的“离线版面列表”中。

```objectivec
[SMConfig addOfflineBoard:self.board];
```
这一步是纯客户端行为，与网络请求无关。
