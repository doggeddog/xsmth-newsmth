# xsmth-newsmth 项目结构分析文档

## 项目概述

xsmth 是一个开源的第三方水木社区客户端（水木社区是中国著名的BBS论坛），基于iOS平台开发。该项目使用Objective-C和Swift混合开发，采用了MVC架构模式，并结合了多种第三方库来实现功能。

## 技术栈

- **开发语言**：Objective-C, Swift
- **平台**：iOS（最低支持版本：13.0）
- **主要依赖库**：
  - ReactiveObjC：响应式编程框架
  - Alamofire：网络请求库
  - WKVerticalScrollBar：滚动条组件
  - ActionSheetPicker：选择器组件
  - TOWebViewController：网页浏览器控制器
  - JPVideoPlayer：视频播放器
  - ASIHTTPRequest：HTTP请求库
  - MMKV：高效的键值存储库
  - Loaf：Toast通知组件

## 项目模块划分

### 1. 核心模块

#### 1.1 数据模型（/newsmth/Data/）

该模块包含了应用所需的数据模型定义，采用了ObjC对象来表示各种数据结构。主要包括：

- **SMBaseData**：所有数据模型的基类
- **SMBoard**：版块信息
- **SMBoardList**：板块列表
- **SMPost**：帖子信息
- **SMPostGroup**：帖子组
- **SMUser**：用户信息
- **SMAttach**：附件信息
- **SMFavor**：收藏相关
- **SMMailItem/SMMailList**：站内信相关
- **SMResult**：接口返回结果封装

该目录还包含数据生成脚本（data.gen.js和_codegen.js），用于生成数据模型代码。

#### 1.2 网络层（/newsmth/Utils/ 和根目录下部分文件）

- **SMHttpRequest**：HTTP请求封装
- **SMWebLoaderOperation**：网页加载操作
- **SMWebLoaderOperationQueue**：网页加载队列
- **SMWebParser**：网页解析器
- **SMNetwork.swift**：Swift实现的网络请求封装

#### 1.3 界面基础（/newsmth/Common/）

- **P2PNavigationController**：自定义导航控制器
- **P2PViewController**：基础视图控制器
- **SMViewController**：水木社区视图控制器基类
- **XWebViewController/XWebController**：网页视图控制器
- **XImageView/XImageViewCache**：图片视图及缓存
- **XPullRefreshTableView**：下拉刷新表格视图
- **XScrollIndicator**：滚动指示器

### 2. 功能模块

#### 2.1 认证与用户（根目录下）

- **SMLoginViewController/SMLoginViewControllerV2**：登录界面
- **SMAccountManager**：账户管理
- **SMUserViewController**：用户信息界面

#### 2.2 主页（/newsmth/mainpage/）

- **SMMainpageViewController**：主页视图控制器
- **SMMainpageCell**：主页单元格
- **SMBoardHistoryViewController**：浏览历史视图控制器
- **SMBoardSearchDelegateImpl**：板块搜索代理实现

#### 2.3 板块相关（/newsmth/board/ 和 /newsmth/boardlist/）

- **SMBoardViewController**：版块视图控制器
- **SMBoardCell**：版块单元格
- **SMBoardSearchViewController**：版块搜索视图控制器
- **SMBoardViewTypeSelectorView**：版块视图类型选择器

#### 2.4 帖子相关（/newsmth/postgroup/ 和 /newsmth/postgroup2/）

- **SMPostGroupViewController**：帖子组视图控制器
- **SMPostViewController**：帖子视图控制器
- **SMPostLinksViewController**：帖子链接视图控制器
- 包含cells目录，存放各种类型的帖子单元格
- 包含postloader目录，负责帖子加载逻辑
- 包含activity目录，可能是帖子相关的活动组件

#### 2.5 发帖功能（/newsmth/write/）

- **SMWritePostViewController**：发帖视图控制器
- **SMImageUploader**：图片上传器
- **SMImageUploadListViewController**：图片上传列表视图控制器

#### 2.6 通知功能（/newsmth/notice/）

此目录包含通知相关的视图控制器和逻辑处理组件。

#### 2.7 更多选项（/newsmth/more/）

此目录包含应用的更多功能选项，如设置、关于等。

### 3. 工具类（/newsmth/Utils/）

- **SMUtils**：通用工具方法
- **SMUpdater**：应用更新
- **SMCryptoUtil**：加密工具
- **SMDBManager**：数据库管理
- **XLogUtil**：日志工具
- **UIView+Utils**：UIView扩展
- **XIPHelper**：IP工具类
- **ip2region**：IP地址区域查询工具

### 4. Javascript解析器（/newsmth/jsParser/）

一个用于解析HTML的JavaScript引擎，是项目中的核心技术点之一。它提供了一套JS方法，用于将HTML解析为JSON数据，便于App使用。这种方式避免了后端API的依赖，直接从网站内容生成所需数据。

## 数据流

应用采用了以下数据流程：

1. 用户操作触发网络请求
2. SMHttpRequest/SMWebLoaderOperation发送请求到水木社区网站
3. 获取返回的HTML内容
4. 通过jsParser对HTML进行解析，转换为JSON数据
5. 将JSON数据映射到对应的数据模型（SMData系列）
6. 数据绑定到UI组件，展示给用户

参考项目根目录下的docs/dataflow.png图表。

## 特色技术

1. **WebParser技术**：无需后端API，直接解析HTML生成JSON数据
2. **混合编程**：Objective-C与Swift混合开发
3. **响应式编程**：采用ReactiveObjC进行响应式编程
4. **动态更新**：解析引擎可动态下载更新，适应网站变更

## 项目结构优势

1. 模块化设计清晰，各个功能模块职责明确
2. 数据模型与视图分离，符合MVC架构
3. 基础组件可复用，提高了开发效率
4. WebParser技术独特，便于适应网站变更

## 总结

xsmth-newsmth是一个功能完备的水木社区第三方客户端，采用了MVC架构模式，结合了多种技术和框架。其核心特色是WebParser技术，能够直接解析HTML生成JSON数据，避免了后端API的依赖。项目结构清晰，模块化设计良好，但仍有一些优化空间，如代码重构、测试覆盖等。总体而言，这是一个设计良好的移动应用项目。
