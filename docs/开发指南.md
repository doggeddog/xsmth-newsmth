# xsmth-newsmth 开发指南

## 开发环境搭建

### 系统要求

- macOS 10.15+
- Xcode 12.0+
- iOS 13.0+ (目标平台)
- CocoaPods 1.10.0+

### 安装步骤

1. **克隆代码库**

```bash
git clone https://github.com/yourusername/xsmth-newsmth.git
cd xsmth-newsmth
```

2. **安装依赖**

项目使用CocoaPods管理依赖，首先需要安装CocoaPods：

```bash
sudo gem install cocoapods
```

然后执行初始化脚本，该脚本会自动安装依赖并准备开发环境：

```bash
./startup.sh
```

3. **打开工程**

安装完成后，打开Xcode工程文件：

```bash
open newsmth.xcworkspace
```

⚠️ 注意：请务必使用`.xcworkspace`文件打开项目，而不是`.xcodeproj`文件，否则会导致依赖库无法正确链接。

## 项目结构概览

项目采用模块化结构，主要目录如下：

- **newsmth/** - 主应用目录
  - **Common/** - 通用组件和基础类
  - **Utils/** - 工具类和帮助方法
  - **Data/** - 数据模型定义
  - **jsParser/** - JavaScript解析引擎
  - **mainpage/** - 主页相关界面
  - **board/** - 版块相关界面
  - **postgroup/** - 帖子相关界面
  - **write/** - 发帖功能相关
  - **notice/** - 通知相关功能
  - **more/** - 更多选项功能

详细的项目结构分析请参考 `docs/项目结构分析文档.md`。

## 开发工作流程

### 1. 理解数据流

xsmth的核心数据流如下：

1. 用户操作触发网络请求
2. 通过SMHttpRequest/SMNetwork发送请求到水木社区网站
3. 获取返回的HTML内容
4. 使用jsParser对HTML进行解析，转换为JSON数据
5. 将JSON数据映射到对应的数据模型
6. 将数据绑定到UI组件

这一流程在`docs/技术架构图.md`中有详细图解。

### 2. 添加新功能的步骤

以添加新的版块功能为例：

1. **创建数据模型**：
   - 在`Data/`目录下创建新的数据模型类，继承自`SMBaseData`
   - 定义必要的属性和转换方法

2. **创建解析脚本**：
   - 在`jsParser/`目录下创建或修改解析脚本，以解析HTML并生成JSON
   - 确保解析脚本能正确提取所需数据

3. **创建网络请求方法**：
   - 在`SMNetwork.swift`中添加新的网络请求方法
   - 使用HTTP请求获取数据并使用解析器解析

4. **创建视图控制器**：
   - 创建新的视图控制器类，继承自`SMViewController`
   - 实现数据加载、展示和交互逻辑

5. **创建UI界面**：
   - 创建XIB文件或使用代码定义UI布局
   - 将UI元素与数据模型绑定

6. **集成到应用**：
   - 在合适的入口点添加对新功能的导航逻辑
   - 在主菜单或其他位置添加入口

### 3. 编码规范

- **命名约定**：
  - 类名使用`SM`前缀（项目相关）或`X`前缀（通用组件）
  - 方法和变量使用驼峰命名法
  - 常量使用全大写字母，下划线分隔

- **注释**：
  - 为所有公共API添加文档注释
  - 复杂逻辑需添加详细注释说明

- **代码组织**：
  - 按功能模块组织代码
  - 保持类的单一职责
  - 将通用功能抽取到基类或分类中

## 常见开发任务示例

### 1. 添加新的板块页面

```objc
// 1. 创建视图控制器
@interface SMNewBoardViewController : SMViewController
@property (nonatomic, copy) NSString *boardID;
@end

@implementation SMNewBoardViewController
- (void)viewDidLoad {
    [super viewDidLoad];
    [self loadBoardData];
}

- (void)loadBoardData {
    [self showLoading];
    [SMNetwork fetchNewBoardWithID:self.boardID completion:^(NSError *error, SMBoard *board) {
        [self hideLoading];
        if (error) {
            [self showError:error];
            return;
        }
        [self updateUIWithBoard:board];
    }];
}
@end

// 2. 在合适的地方添加导航逻辑
- (void)openNewBoard:(NSString *)boardID {
    SMNewBoardViewController *vc = [[SMNewBoardViewController alloc] init];
    vc.boardID = boardID;
    [self.navigationController pushViewController:vc animated:YES];
}
```

### 2. 添加新的数据模型

```objc
// 在Data目录下创建模型
@interface SMNewModel : SMBaseData
@property (nonatomic, copy) NSString *identifier;
@property (nonatomic, copy) NSString *title;
@property (nonatomic, copy) NSString *content;
@end

@implementation SMNewModel
+ (NSDictionary *)JSONKeyPathsByPropertyKey {
    return @{
        @"identifier": @"id",
        @"title": @"title",
        @"content": @"content"
    };
}
@end
```

### 3. 使用jsParser解析HTML

```objc
// 创建解析脚本 (js代码)
var parser = function(html) {
    var doc = document.implementation.createHTMLDocument("example");
    doc.documentElement.innerHTML = html;
    
    var results = [];
    var items = doc.querySelectorAll('.item');
    
    for (var i = 0; i < items.length; i++) {
        var item = items[i];
        results.push({
            id: item.getAttribute('data-id'),
            title: item.querySelector('.title').textContent,
            content: item.querySelector('.content').textContent
        });
    }
    
    return results;
};

// 在Objective-C中使用
NSString *html = /* 获取的HTML内容 */;
NSString *script = [SMWebParser parserForType:SMWebParserTypeNewBoard];
id json = [SMWebParser parseHTML:html withScript:script];
NSArray *models = [SMNewModel arrayOfModelsFromJSONArray:json];
```

## 常见问题与解决方案

### 1. 登录状态丢失

**问题**：用户登录后，在某些情况下登录状态丢失。

**解决方案**：
- 确保正确保存和读取Cookie
- 检查SMAccountManager中的登录状态管理代码
- 定期刷新登录会话

### 2. HTML解析失败

**问题**：由于水木社区网站HTML结构变化，导致jsParser解析失败。

**解决方案**：
- 更新对应的解析脚本以适应新的HTML结构
- 在SMWebParser中添加容错处理
- 实现动态更新解析脚本的机制

### 3. 界面适配问题

**问题**：在不同尺寸的设备上界面显示异常。

**解决方案**：
- 使用自动布局（Auto Layout）确保界面适配各种尺寸
- 为iPad和iPhone设计不同的界面布局
- 使用Size Classes处理不同屏幕尺寸


## 发布与部署

### 1. 版本号管理

在发布新版本前，需要更新版本号：

- 在Xcode中选择项目 → 目标 → General → Identity → Version
- 更新版本号格式为：`主版本.次版本.修订版本`（例如 1.2.3）

### 2. 构建发布版本

构建发布版本的步骤：

1. 选择"Generic iOS Device"或特定设备作为构建目标
2. 选择Product → Archive
3. 在Organizer中选择导出方式（Ad Hoc、Enterprise或App Store）

### 3. TestFlight测试

1. 在App Store Connect中创建新版本
2. 上传构建版本
3. 添加测试人员并发送邀请

### 4. App Store提交

1. 填写App信息、截图和描述
2. 提交审核
3. 发布到App Store

## 贡献指南

### 1. 分支管理

- `master`：主分支，保持稳定可发布状态
- `develop`：开发分支，合并各功能分支
- `feature/xxx`：功能分支，用于开发新功能
- `bugfix/xxx`：修复分支，用于修复bug

### 2. 提交规范

提交信息格式：

```
[类型]: 简短描述

详细描述（可选）
```

类型包括：
- `feat`：新功能
- `fix`：Bug修复
- `docs`：文档更新
- `style`：代码风格改变（不影响功能）
- `refactor`：代码重构
- `perf`：性能优化
- `test`：添加测试
- `chore`：构建过程或辅助工具的变动

### 3. 代码审查

- 所有代码变更需要通过代码审查
- 确保代码符合项目规范
- 验证功能正确性和性能
