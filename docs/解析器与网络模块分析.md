# WebParser与网络模块分析文档

## 1. 模块概述

xsmth-newsmth项目的核心技术之一是通过解析HTML内容直接获取数据，而不依赖API接口。这主要由两个关键模块实现：**jsParser**和**SMNetwork**。本文档详细分析这两个模块的工作原理、API及数据处理流程。

## 2. jsParser模块

### 2.1 基本原理

jsParser模块是一个JavaScript解析引擎，负责将HTML内容解析为结构化的JSON数据。它利用JavaScript的DOM操作能力，通过CSS选择器提取网页中的特定内容。

```javascript

    // ...

};
```

### 2.5 完整解析脚本示例

#### 2.5.1 主页解析脚本

```javascript
var parser = function(html) {
    var doc = document.implementation.createHTMLDocument("example");
    doc.documentElement.innerHTML = html;
    
    var result = {
        hotTopics: [],
        announcements: [],
        recBoards: []
    };
    
    // 解析热门话题
    var hotTopicItems = doc.querySelectorAll('.hot-topic-item');
    for (var i = 0; i < hotTopicItems.length; i++) {
        var item = hotTopicItems[i];
        var topic = {
            title: item.querySelector('.title').textContent.trim(),
            link: item.querySelector('a').getAttribute('href'),
            board: item.querySelector('.board').textContent.trim(),
            author: item.querySelector('.author').textContent.trim(),
            postTime: item.querySelector('.time').textContent.trim()
        };
        result.hotTopics.push(topic);
    }
    
    // 解析公告
    var announcementItems = doc.querySelectorAll('.announcement-list li');
    for (var i = 0; i < announcementItems.length; i++) {
        var item = announcementItems[i];
        var announcement = {
            title: item.querySelector('a').textContent.trim(),
            link: item.querySelector('a').getAttribute('href'),
            date: item.querySelector('.date').textContent.trim()
        };
        result.announcements.push(announcement);
    }
    
    // 解析推荐版块
    var recBoardItems = doc.querySelectorAll('.rec-board-item');
    for (var i = 0; i < recBoardItems.length; i++) {
        var item = recBoardItems[i];
        var board = {
            id: item.getAttribute('data-board-id'),
            name: item.querySelector('.board-name').textContent.trim(),
            description: item.querySelector('.description').textContent.trim()
        };
        result.recBoards.push(board);
    }
    
    return result;
};
```

```javascript
    var result = {

    for (var i = 0; i < postItems.length; i++) {
        var item = postItems[i];
        var post = {
            id: item.getAttribute('data-id'),
            title: item.querySelector('.title').textContent.trim(),
            author: item.querySelector('.author').textContent.trim(),
            postTime: item.querySelector('.post-time').textContent.trim(),
            replyCount: parseInt(item.querySelector('.reply-count').textContent.trim()),
            isTop: item.classList.contains('top'),
            isRead: item.classList.contains('read')
        };
        result.posts.push(post);
    }
    
    // 解析分页信息
    var pagination = doc.querySelector('.pagination');
    if (pagination) {
        var currentPage = pagination.querySelector('.current');
        if (currentPage) {
            result.pagination.currentPage = parseInt(currentPage.textContent.trim());
        }
        
        var pages = pagination.querySelectorAll('a[data-page]');
        if (pages.length > 0) {
            var maxPage = 1;
            for (var i = 0; i < pages.length; i++) {
                var page = parseInt(pages[i].getAttribute('data-page'));
                if (page > maxPage) {
                    maxPage = page;
                }
            }
            result.pagination.totalPages = maxPage;
        }
    }
    
    return result;
};
```

## 3. SMNetwork模块

### 3.1 基本原理

SMNetwork模块是Swift实现的网络请求封装层，负责与水木社区网站交互，获取HTML内容并调用解析器处理。该模块使用Alamofire作为底层网络库，提供了一系列针对水木社区各功能的API。

### 3.2 主要API及实现

#### 3.2.1 主页内容请求

```swift
static func fetchMainPage(completion: @escaping (Error?, SMMainPage?) -> Void) {
    let url = "https://www.newsmth.net/nForum/index"
    
    Alamofire.request(url, method: .get, headers: getCommonHeaders())
        .responseData { response in
            switch response.result {
            case .success(let data):
                if let html = String(data: data, encoding: .utf8) {
                    // 使用WebParser解析HTML
                    let script = SMWebParser.parserForType(.mainPage)
                    if let json = SMWebParser.parseHTML(html, withScript: script) as? [String: Any] {
                        // 转换为数据模型
                        let mainPage = SMMainPage.fromJSON(json)
                        completion(nil, mainPage)
                    } else {
                        let error = NSError(domain: SM_ERROR_DOMAIN, 
                                          code: SMNetworkErrorCodeParseFail.rawValue, 
                                          userInfo: nil)
                        completion(error, nil)
                    }
                }
            case .failure(let error):
                completion(error, nil)
            }
        }
}
```

```swift
                        }
```

```swift
                        let error = NSError(domain: SM_ERROR_DOMAIN, 
                                          code: SMNetworkErrorCodeParseFail.rawValue, 
                                          userInfo: nil)
                        completion(error, false)
                    }
                }
            case .failure(let error):
                completion(error, false)
            }
        }
}
```

#### 3.3.2 Cookie管理

```swift
private static func saveCookies(response: HTTPURLResponse?) {
    guard let response = response,
          let headerFields = response.allHeaderFields as? [String: String],
          let url = response.url else { return }
    
    let cookies = HTTPCookie.cookies(withResponseHeaderFields: headerFields, for: url)
    
    // 保存到用户偏好
    var cookieDict = [[HTTPCookiePropertyKey: Any]]()
    for cookie in cookies {
        var cookieProperties = [HTTPCookiePropertyKey: Any]()
        cookieProperties[.name] = cookie.name
        cookieProperties[.value] = cookie.value
        cookieProperties[.domain] = cookie.domain
        cookieProperties[.path] = cookie.path
        cookieProperties[.version] = cookie.version
        cookieProperties[.expires] = cookie.expiresDate
        
        cookieDict.append(cookieProperties)
    }
    
    UserDefaults.standard.set(cookieDict, forKey: USERDEFAULTS_COOKIES)
    UserDefaults.standard.synchronize()
}

private static func loadCookies() {
    guard let cookieDict = UserDefaults.standard.array(forKey: USERDEFAULTS_COOKIES) as? [[HTTPCookiePropertyKey: Any]] else { return }
    
    for cookieProperties in cookieDict {
        if let cookie = HTTPCookie(properties: cookieProperties) {
            HTTPCookieStorage.shared.setCookie(cookie)
        }
    }
}
```

## 4. SMWebParser模块

### 4.1 基本原理

SMWebParser是连接网络层和解析脚本的桥梁，负责加载和执行JavaScript解析脚本，将HTML内容转换为JSON数据。

### 4.2 主要API及实现

```objc
// 解析HTML为JSON
+ (id)parseHTML:(NSString *)html withScript:(NSString *)script {
    JSContext *context = [[JSContext alloc] init];
    
    // 设置异常处理
    [context setExceptionHandler:^(JSContext *ctx, JSValue *exception) {
        NSLog(@"JS Exception: %@", exception);
    }];
    
    // 执行解析脚本
    [context evaluateScript:script];
    JSValue *parserFunction = context[@"parser"];
    
    if ([parserFunction isUndefined] || [parserFunction isNull]) {
        return nil;
    }
    
    // 调用解析函数
    JSValue *result = [parserFunction callWithArguments:@[html]];
    return [result toObject];
}

// 获取指定类型的解析脚本
+ (NSString *)parserForType:(SMWebParserType)type {
    NSString *fileName;
    
    switch (type) {
        case SMWebParserTypeMainPage:
            fileName = @"main_page_parser.js";
            break;
        case SMWebParserTypeBoardList:
            fileName = @"board_list_parser.js";
            break;
        case SMWebParserTypePostList:
            fileName = @"post_list_parser.js";
            break;
        case SMWebParserTypePostContent:
            fileName = @"post_content_parser.js";
            break;
        case SMWebParserTypeLoginResult:
            fileName = @"login_result_parser.js";
            break;
        // 其他类型...
        default:
            return nil;
    }
    
    // 先尝试从缓存读取
    NSString *cachedScript = [self cachedScriptForFile:fileName];
    if (cachedScript) {
        return cachedScript;
    }
    
    // 从本地加载
    NSString *path = [[NSBundle mainBundle] pathForResource:[fileName stringByDeletingPathExtension] 
                                                    ofType:[fileName pathExtension]
                                               inDirectory:@"jsParser"];
    
    if (path) {
        NSError *error;
        NSString *script = [NSString stringWithContentsOfFile:path encoding:NSUTF8StringEncoding error:&error];
        if (!error) {
            return script;
        }
    }
    
    return nil;
}

// 动态更新解析脚本
+ (void)updateParsers {
    // 从服务器获取最新脚本列表
    [SMHttpRequest requestWithURL:@"https://your-server.com/parsers/list"]
    .startWithCompletionHandler:^(NSData *data, NSError *error) {
        if (error) {
            return;
        }
        
        NSError *jsonError;
        NSDictionary *parsers = [NSJSONSerialization JSONObjectWithData:data
                                                                options:0
                                                                  error:&jsonError];
        if (jsonError) {
            return;
        }
        
        // 检查需要更新的脚本
        for (NSString *parserName in parsers) {
            NSString *version = parsers[parserName][@"version"];
            NSString *localVersion = [self localVersionForParser:parserName];
            
            if (![version isEqualToString:localVersion]) {
                // 下载新版本脚本
                [self downloadParser:parserName version:version];
            }
        }
    }];
}
```

## 5. 数据流程总结

### 5.1 完整处理流程

1. **用户界面触发请求**
   - 用户点击版块、帖子等UI元素
   - 视图控制器调用对应的网络请求方法

2. **网络层发送请求**
   - SMNetwork构建请求
   - Alamofire执行HTTP请求
   - 获取HTML响应内容

3. **解析引擎处理HTML**
   - SMWebParser加载解析脚本
   - 执行JavaScript解析逻辑
   - 使用DOM选择器提取数据
   - 返回结构化JSON数据

4. **数据模型转换**
   - 将JSON转换为对应的数据模型类实例
   - 处理数据格式转换和类型映射

5. **UI绑定与展示**
   - 视图控制器接收数据模型
   - 更新UI组件显示内容
   - 处理用户交互事件

### 5.2 示例：从请求到UI展示


## 6. 技术优势与挑战

### 6.1 技术优势

1. **灵活性**：通过更新解析脚本，可以适应网站HTML结构的变化，无需更新整个应用
2. **独立性**：无需依赖后端API，可直接与网站交互
3. **动态性**：解析脚本可以动态更新，实现热修复
4. **开发效率**：使用DOM操作和CSS选择器，比正则表达式更直观和高效

### 6.2 技术挑战

1. **稳定性**：网站HTML结构变更可能导致解析失败
2. **性能开销**：JavaScript解析可能导致性能开销
3. **维护复杂性**：需要维护多个解析脚本，增加复杂性
4. **调试难度**：跨语言调试（Objective-C/Swift与JavaScript）有一定难度

## 7. 最佳实践

1. **解析脚本测试**：为每个解析脚本编写测试用例，确保解析准确性
2. **容错处理**：解析逻辑中添加充分的错误处理和默认值
3. **版本控制**：对解析脚本进行版本控制，便于回滚和更新
4. **缓存策略**：实现有效的缓存策略，减少重复解析
5. **监控机制**：添加解析失败监控，及时发现和修复问题

## 8. 结论

jsParser和SMNetwork模块共同构成了xsmth-newsmth项目的核心数据获取机制。这种基于HTML解析的方式为应用提供了极大的灵活性和独立性，是项目的一大特色。虽然这种方式有一定的复杂性和挑战，但通过良好的设计和实践，可以有效地克服这些问题，实现可靠、高效的数据获取和处理。
