## 项目简介

xsmth-newsmth 是一个开源的第三方水木社区客户端，基于iOS平台开发。该项目使用Objective-C和Swift混合开发，采用了MVC架构模式，并结合了多种第三方库来实现功能。

项目的核心特色在于其WebParser技术，能够直接解析HTML生成JSON数据，避免了后端API的依赖。这使得App能够直接与水木社区网站交互，而无需额外的后端支持。

## 技术特点

- MVC架构设计
- Objective-C与Swift混合开发
- 响应式编程（ReactiveObjC）
- 模块化设计
- HTML解析转JSON技术
- 动态可更新的解析引擎
